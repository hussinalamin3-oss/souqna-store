# متجر سوقنا الإلكتروني (Souqna E-Commerce) 🛒

منصة تجارة إلكترونية متكاملة ومتجاوبة مع جميع الشاشات، مصممة بواجهة عصرية باللونين الكحلي والذهبي.

## المميزات الأساسية ✨
- **الصفحة الرئيسية:** واجهة ترحيبية (Hero Section) مع عرض لأبرز مميزات المتجر والمنتجات الأكثر مبيعاً.
- **صفحة المنتجات:** عرض شبكي منظم للمنتجات مع إمكانية الإضافة الفورية للسلة.
- **سلة المشتريات:** إدارة كاملة للمنتجات (إضافة، حذف، وحساب الإجمالي تلقائياً) باستخدام `localStorage` لحفظ البيانات.
- **تسجيل الدخول والدفع الوهمي:** نظام تسجيل دخول وحفظ اسم المستخدم، مع نموذج لإدخال عنوان التوصيل واختيار وسيلة الدفع (بنكك، فوري، أو الدفع عند الاستلام).

## التقنيات المستخدمة 🛠️
- HTML5
- CSS3 (Flexbox & Grid)
- Vanilla JavaScript (DOM Manipulation & LocalStorage)
